# Vertical Shooter — 오픈소스소프트웨어 프로젝트 1

방향키로 플레이어 비행기를 이동하고, 스페이스 키로 총알을 발사해 위에서 내려오는 적을 처치하는 종스크롤 슈팅 게임입니다.

## 실행 방법

- Python 3.10–3.13 (Python 3.12 권장)
- Pygame 2.x

```bash
python -m pip install pygame
python main.py
```

## 조작 방법

| 키 | 동작 |
|---|---|
| `Space` | 시작 화면에서 게임 시작 / 게임 중 총알 발사 |
| `←` / `→` | 플레이어 좌우 이동 |
| `R` | 게임 오버 후 새 게임 시작 |
| `Esc` | 게임 종료 |

## 구현 기능

- [x] **F1 플레이어 이동** — 방향키로 좌우 이동하며 화면 경계를 벗어나지 않습니다.
- [x] **F2 총알 발사** — 스페이스 키로 총알을 발사하고, 화면 밖으로 나간 총알은 제거합니다.
- [x] **F3 적 명중과 점수** — 총알과 적의 충돌을 감지해 둘 다 제거하고 적 한 대당 10점을 더합니다.
- [x] **F4 피격과 게임 오버** — 적과 충돌하거나 적을 놓치면 생명이 감소하며, 생명이 0이 되면 게임 오버가 됩니다.
- [x] **F5 재시작과 최고 점수** — `R` 키로 새 게임을 시작하고 최고 점수를 파일에 저장해 다음 실행에도 유지합니다.

## 파일 구성

| 파일·폴더 | 설명 |
|---|---|
| `main.py` | 게임 루프, 입력 처리, 충돌, 점수, 생명, 게임 오버 및 재시작 |
| `entities.py` | 배경, 플레이어, 총알, 적 스프라이트 |
| `settings.py` | 화면 크기, 속도, 게임 규칙 및 파일 경로 설정 |
| `assets/` | 게임 이미지와 `CREDITS.md` 출처 정보 |
| `AI_USAGE.md` | 생성형 AI 사용 기록 |
| `.gitignore` | Python 캐시, 가상환경 및 실행 중 생성되는 최고 점수 파일 제외 |

최고 점수는 게임 실행 폴더의 `highscore.txt`에 저장됩니다. 파일이 아직 없으면 최고 점수는 0점으로 시작합니다.
